# 【第079天 唐山】工业大城的小小滋味

唐山，一个无论何时提起都会略显沉重的名字。

今天的唐山，是一座崭新的城市，宽阔的街道、低密的楼房，怎么都难以让人将它与工业老城的身份联系起来。今天的唐山，也是一座低调的城市，大概很多人不知道它是河北省的经济第一大市。

而它的味道，也是这般低调。

（1）

棋子烧饼

![](images/079-【第079天 唐山】工业大城的小小滋味-c1e229ea/004.jpg)

![](images/079-【第079天 唐山】工业大城的小小滋味-c1e229ea/005.jpg)

![](images/079-【第079天 唐山】工业大城的小小滋味-c1e229ea/006.jpg)

如果你问唐山人，唐山的特色小吃是什么，那么答案一定是异口同声的“棋子烧饼”。棋子烧饼因个头较小、呈圆鼓型如旗子一般而得名。其使用的原料也极其简单，不过是油、盐与面粉，内馅则根据鲜甜口味之分而有各种选择。咬上一口，油、咸、香、酥，一块块饼渣直往下掉，那叫一个爽快。不过到底个头较小，若是不像弄得一地狼藉，一口塞一个也未尝不可。

说起这唐山人对棋子烧饼的热爱，讲讲我今天遇到的情况。大约在中午1点钟来到了这家棋子烧饼店，老板却告诉我只剩下二三十个无馅的，上午卖得太好，全是八斤十斤一堆买的食客。虽有些无奈，却也从心底感到一种深刻的喜悦，一个城市的人疯狂地爱着自己本土的食物，这本就是一件让人着迷的事。

（2）

饹馇

![](images/079-【第079天 唐山】工业大城的小小滋味-c1e229ea/007.jpg)

![](images/079-【第079天 唐山】工业大城的小小滋味-c1e229ea/008.jpg)

![](images/079-【第079天 唐山】工业大城的小小滋味-c1e229ea/009.jpg)

（图为大白菜烩饹馇）

饹馇又名咯扎、格扎，是唐山地区极其流行的一种食物（食材）。尽管在周边地区也能寻得类似的食物（如承德的咯吱），其普遍度远不及唐山。饹馇之名虽然生僻，其不过是用绿豆面摊成的薄饼，然后被制作成菜肴登上唐山的大小餐桌，常见的有烩饹馇、醋溜饹馇、炸饹馇、饹馇汤等做法。以烩饹馇为例，其中的饹馇口感爽滑软嫩、并带有一定的韧劲，有三分类似米粉的口感，相当独特。来到唐山，怎能不吃上一盘带饹馇的菜呢？

（3）

鸿宴烧麦

![](images/079-【第079天 唐山】工业大城的小小滋味-c1e229ea/011.jpg)

![](images/079-【第079天 唐山】工业大城的小小滋味-c1e229ea/012.jpg)

![](images/079-【第079天 唐山】工业大城的小小滋味-c1e229ea/013.jpg)

鸿宴饭庄是唐山市最负盛名的一家老字号食府，下至平民小食、上至山珍海味都可以在这里寻得，而其制作的鸿宴烧麦更是河北省著名的名优小吃。哪怕吃不上大肘子大海参，吃上一屉烧麦也是顶好的味觉体验。

鸿宴烧麦从卖相上便分明地展示出了其皮薄馅大，那神色的肉馅实在太过突出。咬上一口烧麦，肉的咸香满溢出来，却没有厚重的油腻之感，即使不蘸醋也能顺口而下。而其薄薄的皮上有大量的颗粒，吃在口中有明显的粉渣感，这是其他烧麦中不常见的，更丰富了口感体验。

（4）

蜜汁麻叶

![](images/079-【第079天 唐山】工业大城的小小滋味-c1e229ea/016.jpg)

![](images/079-【第079天 唐山】工业大城的小小滋味-c1e229ea/017.jpg)

![](images/079-【第079天 唐山】工业大城的小小滋味-c1e229ea/018.jpg)

孝感麻糖是湖北孝感市著名的地方特产，而实际上，千里之外的唐山，也出产另一种麻糖好几百年了。所谓麻糖，其实就是给炸制的麻叶（又名排叉、由面粉加糖和好后切片油炸而成）裹上糖浆，香甜而酥脆。

而鸿宴饭庄也有着一道从传统唐山麻糖演化而来的甜品——蜜汁麻叶，在炸制好的麻叶上直接浇上蜂蜜，比起包装好的麻糖，能够更加强烈地体会麻叶的酥脆粘牙之感，与香甜的蜂蜜成为绝配。

（5）

迁西板栗

![](images/079-【第079天 唐山】工业大城的小小滋味-c1e229ea/019.jpg)

![](images/079-【第079天 唐山】工业大城的小小滋味-c1e229ea/020.jpg)

请看着我的眼睛，不要说谎。现在仔细回想一下，在以你居住的地方为中心方圆两公里内，是否有一家卖糖炒栗子（板栗）的小摊或小店，打着“迁西”的名号？我想答案七八是肯定的。然而，有多少人知道，迁西属于河北、属于唐山呢？

其实，如果仔细去挖掘一番，可能会发现迁西板栗的迁徙步伐，一点不输于国民三大饮食：兰州拉面、沙县小吃、黄焖鸡米饭，但无奈炒板栗终究不能当饭吃，尽管它无处不在，却总是被人们忽略。这一次，算是为迁西板栗正一次名，让更多的人知道，它来自何方。

低调的唐山，低调的味道。但属于这里的人们，自顾自地疯狂爱着属于这里的味道。我想，如果你有机会来到这里，也要尝一尝这唐山的味道，最好，再听一个唐山人唠叨，他是如何吃着这些味道长大。

哦，对了，一人得有一瓶唐山啤酒。至于要不要嗑上一包板栗，那就随意了。
